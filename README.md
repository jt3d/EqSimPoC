# EqSimPoC: Clear Round

Proof-of-concept for an equestrian career game: a showjumping fun test on rails.
Tilt (or a thumb pad) to balance, tap to ask for take-off and lead changes.

Play: https://jt3d.github.io/EqSimPoC/

Single self-contained `index.html`; three.js is loaded from the jsDelivr CDN.
Tilt needs an HTTPS page opened in Chrome or Safari (motion sensors are blocked in embedded viewers).
